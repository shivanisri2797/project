# Mini Vulnerability Scanner

## 📌 Project Description

This project is a beginner-friendly Python-based vulnerability scanner
developed as part of a cybersecurity internship mini project.

The scanner checks common network ports, identifies basic services,
performs simple banner detection, and generates a vulnerability report.

## 🚀 Features

- Scans common network ports
- Detects open ports
- Identifies basic services
- Performs basic banner/version detection
- Detects simple security risks
- Generates a vulnerability report

## 🛠️ Technologies Used

- Python
- Socket Programming
- Basic Network Security Concepts
